
# adr Uso de observer para avisar al estudiante

## Contexto

El comedor necesita avisar al estudiante cuando su pedido cambie al estado preparado

## Decisión

Se decidió utilizar el patrón observer

El Pedido será el que avise cuando esté preparado y el Estudiante recibira la notificacion

## Alternativas consideradas

Se consideró hacer el aviso directamente desde Pedido pero esto haría que Pedido dependa directamente del estudiante.

También se consideró usar **Strategy** pero ese patrón sirve para cambiar la forma de realizar un comportamiento y no para resolver directamente el aviso del pedido

## Consecuencias

Con bserver podemos avisar al estudiante sin que el pedido tenga que conocer directamente como se realiza el aviso
